GUIDA RAPIDA / 01

Come funziona il laboratorio

Scrivi una domanda nella chat. Nella versione integrata, il modello locale valuta autonomamente se rispondere direttamente o utilizzare uno strumento.

Le schede delle capacità presentano esempi, non obbligano il modello a usare un tool. Lo stato degli strumenti, durante una conversazione, viene mostrato soltanto se comunicato dal backend.

Questa distribuzione è un frontend dimostrativo. Per collegarla al progetto funzionante, configura l'endpoint in config.js.
